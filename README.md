# 🛋️ NexDecor Platform Core

> **The High-Performance Multi-Tenant Engine for Home & Living Brands.**

NexDecor, Next.js 16 ve React 19 mimarisi üzerine inşa edilmiş, saniyede 300K+ isteği (edge-cached) karşılayabilen, Kubernetes tabanlı bir Frontend Platformudur. 

### 🎯 Misyon
Şirket bünyesindeki tüm mobilya markalarını tek bir "Base" çekirdekten, sıfır kod tekrarı ve maksimum performans ile yönetmek.

### 🏛️ ADR (Architecture Decision Records)
Bu projedeki her mimari karar "dip detay" seviyesinde belgelenmiştir:
- [ADR-001] Next.js 16 & React 19 Transition
- [ADR-002] Standalone Dockerization & K8s Scaling
- [ADR-003] Multi-Tenant Design Token Architecture
